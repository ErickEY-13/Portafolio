3) AÑADIR O CAMBIAR UNA DEMO
----------------------------
   a) Deja la grabación original en /media-src (vale MP4, MOV, WebP o GIF
      animado; sin espacios ni acentos en el nombre).

   b) Añade o edita su entrada en la lista JOBS de scripts/optimize-media.mjs:

        {
          input:  'media-src/mi-demo.webp',
          output: 'public/projects/video/mi-demo.mp4',
          poster: 'public/projects/mi-demo-poster.webp',
          width:  1280,   // 640 si la grabación es vertical
          crf:    30,     // más alto = más comprimido y peor calidad
        }

   c) Instala las herramientas, convierte y desinstálalas:

        npm install -D ffmpeg-static sharp
        npm run media
        npm uninstall ffmpeg-static sharp

   d) Apunta el proyecto al resultado en src/data/site.js:

        media:  'projects/video/mi-demo.mp4'
        poster: 'projects/mi-demo-poster.webp'

   Para ver cuántos fotogramas y qué duración tiene un archivo:
        npm install -D sharp && npm run media:info -- media-src/mi-demo.webp


   Qué hace la conversión:
     · WebP/GIF animado → MP4  (pesa entre 5 y 10 veces menos)
     · vídeo            → MP4 recomprimido y listo para streaming
     · saca un póster en WebP del segundo 2 de cada vídeo
     · los originales de /media-src no se tocan

   Nota: ffmpeg por sí solo NO sabe leer WebP animado (ignora los chunks
   ANIM y ANMF). Por eso el script extrae los fotogramas con sharp y se los
   pasa a ffmpeg por stdin.


   El material vertical se muestra entero y centrado; el apaisado se recorta
   a sangre. Se detecta solo al cargar los metadatos.
